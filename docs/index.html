🧪 Advanced mode

P1xel Lab's own take on MCreator. It opens in its own window and makes real Java mods for Fabric 1.21.1.

  • Element buttons: Item, Block, Food, Sword, Pickaxe. P1xel Lab writes the Java code, models, textures, loot and recipes.
  • Plugins add more elements, like ores and enchantments.
  • A real code editor for every file, with a pixel editor for textures.
  • 🔨 Build in one click (Java 21 and Gradle download automatically), then ▶ Add to instance and play.

Make your own plugin

A plugin is one .json file of templates. It can add files, code to ModItems, ModBlocks or ModMain, tags and names. Plugins never run code inside P1xel Lab, so they're safe to install.

Copy an example. Start from custom-ore.json or custom-enchantment.json.
Add fields (text, number, select or bool) that show up in the element form.
Use placeholders like {{id}}, {{ID}}, {{modid}}, {{name}} and your field ids in files and code.
Test it with Install from file, then share it. Want it listed here? Send it to VividP1xels!
