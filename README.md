# P1xel Lab

A Minecraft: Java Edition launcher built for modding, by **[VividP1xels](https://www.youtube.com/@VividP1xels)**.

1. **Sign in with Microsoft.** Uses the official Microsoft login window. Your session is saved (encrypted) so you stay signed in.
2. **Tutorial.** A 5-step walkthrough of instances, mod loaders, searching for mods, and installing them. You can replay it from Settings.
3. **Make your first instance.** Pick a name, a Minecraft version, a loader (Fabric, Quilt or Vanilla) and a pixel-block icon.
4. **Search and install mods in the launcher.** Switch between **Modrinth** and **CurseForge**. Results only show mods that work with the instance's version and loader. One click downloads the right file into the instance, along with any required mods it depends on (like Fabric API).
5. **Play.** The launcher downloads the right Java version (Temurin), the loader, the game files and assets, then starts Minecraft. Game output appears in the **Game log** tab.

6. **Browse mods offline.** Every mod you see while online is saved on your computer with its icon. P1xel Lab also saves the 150 most popular mods for each instance in the background. With no internet, you can still search and browse those saved mods, and play instances you've already played. Installing new mods needs internet.
7. **Friends.** Add people by their Minecraft username. Text chat (with delivered ticks and "typing…"), voice calls, video calls, and sharing a whole instance, so a friend can add the same modpack in one click. Each friend shows **Online**, **Offline** or **Playing &lt;instance&gt;**, and your own status follows your Wi-Fi connection. You can remove or block anyone.

8. **Forge and NeoForge.** Instances can now use Fabric, Quilt, Forge, NeoForge (beta) or Vanilla, so big and horror mods that are Forge-only work too.
9. **Smarter search.** Typing a file name like `wonderland_forge_1.20.1.jar` searches for "wonderland". If nothing fits your instance, P1xel Lab shows every version and offers **Make instance for it**, which creates a matching instance and installs the mod. You can also add `.jar` files from anywhere with **Add .jar file** or by dragging them onto the window.
10. **Servers.** Host Vanilla, Paper (plugins), Fabric, Forge or NeoForge servers on your own computer for free.
    - RAM from 0 to 10,000 GB, or **♾ Unlimited**. It can never use more than your PC really has, so it uses all the RAM the computer can spare, and the screen shows exactly how much.
    - Content tab: add mods, plugins, data packs, a server resource pack, and **Player Pack** extras (shaders and player-side mods), from Modrinth/CurseForge or your own files. Client-only mods automatically move into the Player Pack.
    - **Invite + send Player Pack** lets friends add everything they need in one click.
    - Settings: name, MOTD, port, server IP (bind address), icon, game mode, difficulty, PvP, hardcore, whitelist, view distance, seed, world type and more. Your public IP is shown, but it comes from your internet provider and can't be changed.
    - Players tab (op, kick, ban, whitelist), console with quick commands, backups (make, restore), new world, auto-restart after crashes, backup on stop, ⚡ server Speed Boost.
    - **🌐 Any version:** ViaVersion + ViaBackwards + ViaRewind on Paper, ViaFabric + ViaBackwards on Fabric. Instances get ViaFabricPlus (Fabric/Quilt) or ViaForge (Forge/NeoForge) with the **🌐 Any Version** button.
    - Friends outside your Wi-Fi need [playit.gg](https://playit.gg) (free) or port forwarding.
11. **Create** (sidebar). Three makers in one tab:
    - **Mods & Data Packs:** custom commands (`/trigger pixel` on any version from 1.13 up, real `/pixel` on Paper servers), crafted custom items (1.21 to 1.21.4), starter kit, spooky nights and more. Fabric/Quilt 1.21 to 1.21.4 get a mod `.jar`, and everything else gets a data pack. Add to instances or servers, or export.
    - **Resource Packs:** pick any item, block or mob texture from the game and repaint it in a pixel editor (pencil, fill, eraser, color picker, undo). It's added and turned on for you.
    - **Shaders:** looks like Vivid, Horror, Retro, Noir, Underwater and more, with sliders and a live preview. Builds a real Iris/OptiFine shader pack and turns it on.

    Old Mod Maker notes: Make a real mod with no coding: custom crafted items with their own name, color, enchantments, damage and glow, a starter kit, keep inventory, night vision, a welcome message and **spooky nights**. Draw a pixel icon, then add it to an instance or export the `.jar`. Works on Fabric/Quilt for Minecraft 1.21 to 1.21.4.
12. **⚡ Speed Boost.** One click adds ModernFix, FerriteCore, Sodium (or Embeddium), Lithium, ImmediatelyFast and Entity Culling. They make Minecraft start faster, use less memory and run at a higher FPS. It's on by default for new modded instances. Game files also download 32 at a time instead of 2, and Java uses settings tuned for Minecraft.

13. **Shaders, resource packs, data packs and modpacks.** The Browse tab has a tab for each type, from both Modrinth and CurseForge. Shaders add Iris (or Oculus on Forge) for you. Data packs are added to every world in the instance when you press Play. Modpacks install as a new instance with the right Minecraft version, loader and files. You can also import a `.mrpack` or CurseForge modpack `.zip` from the New instance screen.
14. **Publish.** Share things you made: a Mod Maker mod or your own `.jar`, any instance as a modpack (`.mrpack`), a resource pack, a Mod Maker data pack or your own, or a shader. Save the file to share anywhere, or publish it on Modrinth with your own Modrinth token. It's uploaded as a draft, and you click **Submit for review** on Modrinth. CurseForge only allows new projects on its website, so save the file and upload it there.

15. **Profile and feed.** Launcher-only display name (your real Minecraft name is still shown), status, bio, banner color, YouTube link and favorite modpack. Choose who sees it: all friends, or only you. Post text, pictures and videos (up to 40 MB), edit or delete them, and ❤ friends' posts. Posts reach friends who are offline later, too.
16. **Skins and capes.** Create → Skins: pixel editor with front/back preview, classic or slim arms, import/export PNG, a skin library, and **Wear this skin** to put it on your Minecraft account. Pick or hide your capes.
17. **Any color.** An RGB color picker (sliders, hex, recent colors) everywhere in Create, for Mod Maker item names, and for the launcher's own theme color.
18. **Private sharing.** Send mods, packs and modpacks straight to a friend (📎 in chat, or Publish → Send privately). On Modrinth, choose Public, Unlisted or Private.
19. **More.** Worlds tab (back up, open, delete), Screenshots gallery (post to your feed), one-click mod updates, and playtime for each instance.
20. **🎛 Customize.** Background picture (with darken and blur), text size, font, square corners, compact mode, sidebar width, animations, button sounds, which sidebar buttons show, and which page opens first.
21. **📥 Import a server.** Pick a server folder or `.zip`. P1xel Lab detects Vanilla, Paper/Purpur/Spigot, Fabric, Forge or NeoForge and the Minecraft version, then brings in the world, settings, mods, plugins, data packs, resource packs and texture packs. **🎮 Make instance** builds a matching instance so you can join.
22. **Texture packs.** A Texture Packs category in Browse (filter by 16x, 32x, 64x…), a 🎨 Textures tab in Mod Maker that builds your own texture packs into a mod, and a 🎨 Retexture element in Advanced mode.
23. **Mod pages.** Full description, pictures, every version with its changelog, and **install any older version** to roll back. Sort by Newest or Recently updated.
24. **Collections, export and compare.** Save mods into collections and install a whole collection at once, export an instance's mod list, and compare two instances.
25. **Worlds and maps.** Import a world `.zip`, or download maps from CurseForge (Browse → Worlds & Maps).
26. **Instance pictures and folders, 🥔 Potato mode, crash helper** (explains crashes in plain English and offers fixes), **keyboard shortcuts** (F1 shows them), **profile badges**, and **automatic daily server backups**.

## Downloads

Every build makes:
- **Windows:** `P1xel-Lab-Setup.exe` or `P1xel-Lab-Portable.exe`
- **Mac** (Intel and Apple Silicon): `P1xel-Lab-Mac.dmg`. The app isn't signed with a paid Apple certificate, so the first time, right-click P1xel Lab and choose **Open**.
- **Linux:** `P1xel-Lab-Linux.AppImage` (any distro: `chmod +x`, then run it) or `P1xel-Lab-Linux.deb`

Latest: https://github.com/VividP1xels/p1xel-lab/releases/latest

## How friends work

- Launchers connect to each other directly (peer-to-peer) using [PeerJS](https://peerjs.com)'s free public connection service, so there's no server to run.
- Nobody can pretend to be someone else. Before anything is accepted, each launcher proves it owns its Minecraft account using Mojang's own check, the same one Minecraft servers use.
- Profiles and posts can be shared with all your friends or kept private. They can't be fully public, because there's no central server.
- Both friends need P1xel Lab open and be online for messages to send. Messages written while a friend is offline are kept and sent the next time you're both online.
- Calls connect directly, so a friend you call can see your IP address, like in most games' voice chat. Only people you've accepted as friends can message or call you.

## Run it

You need [Node.js 18+](https://nodejs.org).

```bash
npm install
```

```bash
npm start
```

## Build an installer

```bash
npm run dist:win
```

Use `npm run dist:mac` on a Mac and `npm run dist:linux` for an AppImage. The output goes in `dist/`.

## CurseForge API key

Modrinth works without a key. CurseForge requires each launcher to use its own free API key:

1. Go to https://console.curseforge.com/ and create an account.
2. Copy your API key.
3. In P1xel Lab, switch to CurseForge in **Browse mods**, or open **Settings**, and paste the key.

Some CurseForge authors turn off downloads from third-party launchers. For those mods, P1xel Lab opens the download page in your browser. Put the file you download into the instance's `mods` folder (use **Open folder**).

## Where things are stored

All data lives in the app's user-data folder (`%APPDATA%\P1xel Lab` on Windows):

- `instances/<name>/`: each instance's game folder (mods, saves, config)
- `minecraft/`: shared game versions, libraries and assets
- `java/`: Java runtimes the launcher downloaded

## Before releasing it publicly

- **Microsoft login:** sign-in uses the [msmc](https://github.com/Hanro50/MSMC) library with its default client ID. That's fine for personal use. To distribute the launcher to lots of people, register your own Azure app and [apply for Minecraft API access](https://aka.ms/mce-reviewappid), then pass your client ID to msmc in `main.js`.
- **Forge and NeoForge** aren't supported yet. Only Fabric, Quilt and Vanilla instances can be launched.
- Unsigned builds show a SmartScreen or Gatekeeper warning until you sign them with a code-signing certificate.
